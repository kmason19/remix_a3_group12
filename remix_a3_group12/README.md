# SmartPark Application 

## Project Overview
SmartPark is a blockchain-based parking management system designed for hotel environments. The application allows parking space providers to manage parking spaces while enabling parking users to search, book, and pay for parking spaces through blockchain smart contracts. The system improves transparency, security and trust by recording booking and payment transactions on a decentralised blockchain network. 

## Features 
- Create new parking spaces
- Update parking space information
- Delete/deactivate parking spaces
- Manage parking space availability
- Create parking bookings
- Process booking payments
- Cancel bookings and refunds
- Blockchain-based transaction recording

## Smart Contracts 

### ParkingSpaceManagement.sol 
This smart contract manages parking space information within the SmartPark application. 

Functions include:
- Create parking spaces
- Update parking spaces
- Delete/Deactivate parking spaces
- Manage parking space availability
- Retrieve parking space details

### BookingAndPayment.sol 
This smart contract manages parking bookings and payment transactions. 

Functions include:
- Create bookings
- Process payments
- Cancel bookings
- Complete bookings
- Process refunds

## Stakeholders 

### Parking Space Provider 
Supplies, registers and manages parking spaces on the SmartPark application. 

### Parking User 
Searches, books and pays for parking spaces through blockchain-based transactions. 

### Blockchain system 
Validates, records and securely stores parking, booking and payment transactions through smart contracts. 

## Technologies Used 
- Solidity

## How to Run the Project 
1. Open Remix IDE
2. Upload the Solidity smart contract files
3. Compile the contracts using Solidity version 0.8.0
4. Deploy the contracts using Remix VM
5. Test the contract functions through the Remix interface
